# About PlainSv

PlainSv is a collection of accessible Svelte 5 components that follow the shadcn design, written the Svelte way. Each component keeps its state in runes, its styles in a scoped `<style>` block, and builds on native elements such as `dialog` where the browser already does the work. There is no Tailwind, no PostCSS setup, and no headless UI library underneath.

Start building by editing `src/routes/(typeset)/about/+page.svx`
